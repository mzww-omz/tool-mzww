# TOOLBOX

日々の作業に使う56種類の道具（初期15＋追加21＋追加20）。Svelte 5 + TypeScript + SvelteKit + Tailwind CSS v4 / Vite。処理はすべてクライアントサイドで実行します。アカウント、サーバーDB、外部API、CDN、外部フォント、解析サービスはありません。通常の入力はメモリ内のみ、既存のメモ・予定だけIndexedDBに端末内保存します。ツールとOSSライブラリは該当ツールの選択時に遅延読み込みします（依存関係の表を参照）。

## 起動・検証

Node.js **22.18以上**（ViteとNodeのTypeScript実行機能を使用）。

```sh
npm ci                 # 初回のみ
npm run dev -- --port 5174
npm test               # 全56ツールのロジック・境界値（63テスト）
npm run check          # Svelte / TypeScript検査。警告も失敗扱い
npm run build
npm run preview -- --port 4174
```

`/` は文字数カウンター、`/tools/:id` で全56ツールへ直接アクセスできます。Viteのビルドとは別に、`svelte-check` / TypeScriptによる型検査を実行できます。

### ブラウザ統合テスト

`tests/browser-smoke.mjs` と `tests/browser-extended.mjs` はPlaywrightのPageを受け取る統合テストです。前者は初期15ツールの入出力、画像ダウンロード、コピー、入力保持、お気に入り・履歴・検索・キーボード・レスポンシブ・未登録IDを維持検証します。後者は追加21ツール、URLのフォーム形式、実際のShift_JISファイル、QRのPNG/SVG保存・対応ブラウザでの読み取り、メモの再読み込み・入出力・予定のCRUD、GPS座標の模擬入力と権限拒否、IndexedDB利用不可、正規表現のWorkerタイムアウト、時計・タイマー・シャトルラン・全画面表示、320px表示を検証します。タイマーは時計を2分進めた際の期限判定も確認します。GPS実機の精度、通知音の可聴性、運動ペースのハードウェア校正までは検証しません。

`tests/browser-new.mjs` は番号37〜56の主要操作、全56ツールの直接URL、任意Tailwindクラス（引用符なしHTML属性も含む）の実スタイル、XSS隔離・外部取得なし、実ZIP・JPEG/PNG/WebP・PDF保存、壊れたファイル、Worker利用不可、入力保持、画面API失敗時の代替表示・キーボード、20画面の320px表示を検証します。ダウンロード後のWorker終了・Blob URL解放も確認します。スクリーンショットは `/tmp/toolbox-screenshots/` に出力します。全ブラウザ・実ディスプレイ・巨大な悪意あるファイルに対する網羅的検証ではありません。

アプリと既存のPlaywright / Chrome環境が起動・利用可能な状態で:

```sh
# Playwrightがプロジェクトから解決できる場合
npm run test:browser

# 別の場所にインストール済みのPlaywrightを再利用する場合
PLAYWRIGHT_MODULE=/absolute/path/to/playwright-core/index.mjs npm run test:browser

# 本番プレビューを対象にする場合
TOOLBOX_URL=http://127.0.0.1:4174 npm run test:browser
```

初期値は `http://127.0.0.1:5174` とChrome。`PLAYWRIGHT_CHANNEL` で変更できます。ブラウザテスト用パッケージやブラウザ本体の自動ダウンロードはしません。

## 構成

```text
src/lib/
  Shell.svelte             # 固定ワークスペース・ナビゲーション・保存
  registry.ts              # メタデータの自動発見・検索
  types.ts                 # レジストリの契約
  components/              # コピー・出力・テキスト変換UI
  tools/<id>/
    index.ts               # ID、表示名、英語名、別名、カテゴリ、遅延ロード
    Tool.svelte            # そのツール専用の自由なUI
    logic.ts               # DOMに依存しない処理・テスト対象
src/routes/
  +layout.ts               # SSR無効（入力はクライアントのみ）
  +layout.svelte           # ルート切り替えで破棄しないShell
  tools/[id]/+page.svelte  # 共通の直接アクセスルート
```

### ツールの追加

1. `src/lib/tools/<一意のid>/` を作成。
2. `index.ts` から `ToolDefinition` に適合するオブジェクトをdefault export。既存モジュールを参考に、`load: () => import('./Tool.svelte')` を指定。
3. `Tool.svelte` は `state` を `$bindable()` プロパティとして受け取り、入力・結果を保持。デフォルト値は `untrack` 内で未設定時のみ初期化する。
4. 処理を `logic.ts` に置き、`tests/*.test.ts` にテストを追加。
5. 保存を明示するツールのみ `persistent: true` をメタデータに設定。これはプライバシー説明用で、保存機構そのものは各ツールで実装します。

レジストリ・カテゴリ・検索・ルート・既存画面の修正は不要です。メタデータのみ最初に読み込み、UIと処理は選択時にチャンク単位で読み込みます。カテゴリは複数所属でき、最初のカテゴリを一覧の見出しに使います。検索は日本語・英語・別名・カテゴリをNFKC正規化し、大文字小文字を区別せず、空白区切りのAND検索を行います。

1,000ツール分の実データによる性能検証は未実施です。現時点ではメタデータのクライアント検索と通常のリスト描画を採用しています。将来、実測で必要になった時点で仮想スクロール等を検討してください。

## 保存・プライバシー

- 通常の入力・結果・画像はメモリ内のみ。ツール切り替えでは保持され、再読み込み・タブを閉じると消えます。
- メモとカレンダーの予定は **IndexedDB**（`toolbox-local` の `notes` / `events`）に端末内保存します。サーバー・他端末への同期や暗号化はしません。ブラウザのデータ削除で失われるため、重要なメモはJSONでバックアップしてください。
- キーボード入力は画面内の最新イベントと押下状態だけ。フォーカス喪失・画面切替で消去し、共有状態やストレージには残しません。
- GPSはユーザーが測定開始した後だけ取得。比較用の直前座標1点だけをメモリに持ち、停止・画面切替で破棄します。経路や座標履歴は保存しません。
- お気に入りと最近使用20件の **ツールIDのみ** をlocalStorageに保存。
- localStorageが無効でも動作し、保存できない旨を画面に表示。
- アプリ資産の取得以外にネットワーク通信しません。データ送信・外部API呼び出しはありません。
- Clipboard / Web Crypto用にHTTPSまたはlocalhostで利用してください。
- `⌘ / Ctrl + K` で検索、Escapeでモバイル一覧やヘルプを閉じます。ライフゲームは矢印キーとSpaceで編集できます。

### シャトルランのペースと安全

2026-10-21に [Topend Sports: 20m Multistage Fitness Test](https://www.topendsports.com/testing/tests/20mshuttle.htm) の8.5km/h版の表を確認し、その各レベルの速度・本数を実装しています。初速8.5km/h、レベルごとに0.5km/h増加、レベルごとの本数は `7, 8, 8, 8, 9, 9, 10, 10, 10, 11, 11, 12, 12, 13, 13, 13, 14, 14, 15, 15, 16` です。テストには複数の方式があり、日本の新体力テスト音源等と一致するものではありません。出典の音源・第三者の公式音源をコピーせず、Web Audioの発振器で音を合成します。

音声の先行スケジュールを行いますが、スマートフォンの音声出力遅延やブラウザの停止は制御できません。画面非表示・500ms超の進行遅延では停止し、遅れたビープをまとめて再生しません。開始前に安全な20m区間と音量を確認し、体調不良・痛み・息苦しさ・めまいがある場合は実施／継続しないでください。終了ボタンは常に操作可能です。

### プレビュー・ファイル処理の安全性

- HTML/CSSプレビューは空の `sandbox` 属性を持つiframe。スクリプト・同一オリジン権限・フォーム等を許可しません。
- CSPで `default-src 'none'`、スタイルはインラインのみ、画像・フォント・base・フォームを禁止。HTMLは許可した要素とclass等だけを残し、リンク先やイベント属性も除去します。CSS内の `<` はエスケープしstyle要素からの脱出を防ぎます。
- MarkdownはHTML無効のパーサーとURL検証を使い、画像を生成しません。保存HTMLにもCSPを付けます。
- ZIP作成・画像バイナリ処理・PDF処理・TailwindコンパイルをWorkerへ分離し、時間切れ・画面切替で終了。Workerへ渡すPDFのSvelte状態はsnapshot化します。
- ファイル読み込み・保存はブラウザAPIのみ。元ファイルは変更せず、ダウンロード用Blob URLは使用後に解放。画像デコーダー等の内部メモリ・全ブラウザの挙動まで完全に制御するものではありません。

### 依存関係と採用理由

すべてnpmからビルド時に取り込み、実行時にCDN等を利用しません。バージョンの正確な固定は `package-lock.json` を参照。`npm install` 時点の監査は脆弱性0件でしたが、将来の安全性を保証しません。
